# 小学数学 · 竖式闯关

给小学生练计算用的互动网页：**一年级到六年级一条线闯关**，每一题都用竖式呈现，可以用拨轮转或键盘打两种方式答题，答错能看**边动边念**的逐步讲解（动画演示 + 中文朗读）。

**线上地址：<https://sx2.9i9i.cn>**（打开就是闯关页，iPad 上直接玩）

## 两个页面

| 文件 | 内容 |
|---|---|
| `vertical.html` | **竖式闯关**（主页面）。33 个关卡、拨轮输入、动画 + 语音讲解 |
| `index.html` | 人教版 1–6 年级**知识纲要**（94 个单元，可搜索）＋ 30 个出题器入口 |

两页互相链接，纯静态、无外部依赖，双击就能在浏览器打开。

## 闯关规则

- 一关 = 一个年级里的一个具体内容，**连对 10 题**自动通过并进入下一关
- 答错即中断连对，从头累计
- 进度存在浏览器 `localStorage`（key `pm_path_v2`），关掉再打开会接着上次的关卡
- 家长想直接跳到某个年级：展开顶部面板 → 「解锁全部关卡」

## 两种答题方式

顶部面板里可切换：

| 方案 | 说明 |
|---|---|
| **A 拨轮转动** | 每位是一个数字轮，手指按住上下拖动，数字实时跟手、松手吸附；上下各露出半格相邻数字，像调密码锁。**iPad 上最好用** |
| **B 键盘输入** | 在竖式格子里直接打字，自动跳下一格 |

**进位 / 退位**是独立的操作，两种方式都能用：标记就在竖式正上方那一行，点一下就循环 `+1 → +2 → +3 → 空`（减法为 `−1 → −2 → −3 → 空`）。乘法里需要更大的进位时，循环上限会按正确答案自动放宽（例如进 8 就能点到 +8）。没标或标错，检查时那一位会亮红圈。

## 讲解

点题目右下角的「讲解」，竖式会**一边动画演示一边用中文念出来**，动画和语音同一步走：

- 正在算的那一列整体亮起并轻微放大
- 竖式下方浮出这一位的算式（如 `5 + 9 = 14`、`百分位 0 + 7 = 7`、`21 × 2 = 42`），气泡的小箭头指着那一列
- 同一句话从喇叭里念一遍："个位：5 加 9 等于 14。满十，写 4，向十位进 1。"
- 进位标记同时"弹"到上方对应位置，结果数字逐位落下（拨轮会自动滚到正确的数）
- 右侧步骤列表同步高亮当前行

节奏是**念完一句才走下一步**：数字 0.43s 后就落下，语音多长就等多久，不会出现"动画跑完了话还没说完"。

语音可以在顶部折叠面板的「讲解方式」里用开关关掉（状态记在 `localStorage` 的 `pm_voice_v1`），关掉后只播动画、按固定节奏走。发音走系统 TTS：iPad 上是「婷婷」，Chrome 上是 Google 普通话；`÷ × + =` 会先转成「除以 / 乘 / 加 / 等于」再念，避免读出符号怪音。

> iPad 的规矩：页面必须被手指点过一次才允许出声。所以第一句由「讲解」按钮的点击直接触发（同步调用，不放在 `await` 之后），后续句子不会被拦。

长除法这类很高的竖式，气泡会跑到屏幕外，此时页面会自动小幅滚动把它带回来。

右侧「讲解步骤」默认是空的（只留一句提示），点了「讲解」或「检查」才把每一步列出来，免得孩子先抄答案。

## 技术要点

- 单文件 HTML + 原生 JS，无框架、无构建步骤
- 竖式用 CSS Grid 渲染，列宽由 JS 按位数生成（小数点列 24px，其他 58px；移动端 20/50px），每个 cell 显式指定 `grid-row` 避免回流错位
- 题目由构造器生成：`buildAddSub`、`buildMul`、`buildMulN`（多位数乘法，两行部分积都是待填）、`buildDiv`（长除法，先贪心取够比除数大的前缀再起商）
- 每个构造器返回 `{expr, cols, rows, inputs, carries, steps, answer}`，渲染、判题、讲解都基于这份结构
- 每一步还带一个 `ex` 字段（这一位的简明算式），讲解气泡直接用它，不必再解析文字说明

## 本地运行

```bash
open vertical.html    # macOS，直接双击也行
```

无需服务器。改完刷新即可看到效果。

## 部署

线上挂在阿里云轻量服务器（120.24.67.166）上，由 `/opt/sweettalk-wework/server.js` 这个 Node 网关按 Host 分发静态目录，HTTPS 走 Let's Encrypt 证书。
